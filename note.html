Linux 作業系統筆記

1. 主機名稱

hostname：查看主機名稱

2. 查看主機 IP

hostname -I：查看主機

3. 新增使用者

sudo useradd 使用者名稱

4. 設定密碼

sudo passwd 使用者名稱

5. 確認目前使用者

whoami

6. 變更使用者及群組

chown -R 使用者:群組 目錄檔案 或 chown -R 使用者.群組 目錄檔案

7. 查詢目錄檔案

ls、ls -a、ls -l、ls -al：皆可以查詢目錄下的檔案，指示查詢的細項不同。ls -al顯示最詳細的資料(在Linux中任何檔案開始為 . 的檔案即為隱藏檔)。

8. 生成空白檔

touch a

9. 刪除檔案

rm -i

10. 強制刪除檔案

rm -f

11. 使 .bashrc 的變更生效

修改 .bashrc 後，需執行以下其中一個指令： 重新連接、source .bashrc或 . .bashrc

12. 清空檔案

>a.txt或1>a.txt

13. 輸出結果至檔案

ls 1>ok.txt 2>error.txt：會生成 ok.txt 和 error.txt 的檔案，當 ls 正常執行，ok.txt 中會顯示內容，error.txt 為空白檔案；當 ls 執行失敗，ok.txt 為空白檔案、error.txt 會顯示內容。

補充

0：標準輸入
1：標準輸出
2：標準錯誤輸出

14. 錯誤輸出重定向

2>&1：把標準錯誤輸出導向跟標準輸出一樣，當想在檔案中同時看到正確跟錯誤訊息。

15. 合併檔案

cat a.txt b.txt > c.txt：將 a.txt 跟 b.txt 合併成 c.txt。

16. 條件搜尋檔案

find /usr/lib/ -name "*test*"：在 /usr/lib/ 目錄下尋找名字含有 test 的檔案。

通配符

*：多個任意字元

?：單個字元

17. 系統與網路基本指令

poweroff：關機
reboot：重新開機
ifconfig (或 ip a)：查詢網路

18. 查看檔案內容

more：會分頁，只能往下
less：會分頁，可以往上、往下
cat：查看檔案內容
tail -n 5 /etc/passwd：看檔案最後 n 筆（例如查看 /etc/passwd 最後 5 筆資料）
head -n 5 /etc/passwd：看檔案前面 n 筆（例如查看 /etc/passwd 前 5 筆資料）

19. 尋找檔案工具

find：常搭配 -name、-size 等參數進行搜尋
which：去 $PATH 所記錄的資料夾中搜尋可執行檔
locate：搜尋前要執行 sudo updatedb 更新資料庫

20. Docker 容器管理

sudo docker rm -f container_id：強制刪除正在執行的 docker 容器。

21. 指令別名設定

alias mycopy="cp -r"：把 cp -r 指令取別名為 mycopy。

22. 終端機快捷鍵

ctrl+A：跳到指令最前面
ctrl+E：跳到指令最後面

23. 背景執行工作

sleep 10000 &：把 sleep 10000 丟到背景執行。

24. 背景工作管理

執行 jobs 查詢目前有哪些程式在背景執行，會顯示工作數字。輸入 fg 數字會讓該背景工作跑回前景執行。

25. 系統程序查詢

ps -ef：查看全系統程序（進程）的執行情況。

26. 免除掛斷執行

nohup：讓指令在背景運行，即使關閉終端機仍會繼續執行。

27. grep

grep [參數] "關鍵字"
參數：
-A：after多顯示匹配行之後的幾行
-B：before多顯示匹配行之前的幾行
-i：不分大小寫
-v：排除在外（反向選擇）
-n：加上n會列出該關鍵字所在的行數，例如：grep -n aa 1.txt 2.txt

28. grep

grep -n aa l.txt 2.txt加上n會列出這兩個檔案中有aa的行數

29. 進階檔名匹配 (中括號)

ls a[bc]：匹配a後面帶有b或c的檔案（例如ab, ac）

30. 進階檔名匹配

ls a[^0-9]：匹配a後面不是數字的檔案（例如aa, ab）

31. 查看系統功能

top：即時查看系統功能與資源使用率（CPU、記憶體、程序）

32. 磁碟空間查詢

df -h
